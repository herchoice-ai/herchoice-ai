# Roadmap

Dates assume funding starts in March 2027. They shift with the actual start date.

## Months 1–3 (Mar–May 2027): Build and open

- 500 clinician-approved Hausa answers in the content library
- Hausa speech-to-text fine-tuned on local voice data, including Hausa–English code-switching; accuracy tested with 100 users
- Hausa voice replies (text-to-speech) enabled on WhatsApp, using a voice licensed for commercial deployment (the default MMS model is non-commercial; see NOTICE)
- Public release of code (Apache 2.0) and content (CC BY 4.0)

## Months 4–6 (Jun–Aug 2027): Pilot

- Live in 2 local government areas in Kano State
- 2,000 women and girls using the service
- 30 verified health workers and protection services in the referral directory
- Voice line (IVR) channel for basic phones

## Months 7–9 (Sep–Nov 2027): Strengthen

- Independent privacy and safeguarding audit
- Pregnancy danger-sign module
- Anonymised indicator export for DHIS2
- USSD channel
- Agreement with a State Primary Health Care Board

## Months 10–12 (Dec 2027–Feb 2028): Scale

- 10,000 users across 3 local government areas
- First paid institutional licence
- Public impact report: reach, completed referrals, knowledge gain, safety cases handled, user trust

## Success measures

| Measure | How |
|---|---|
| Women and girls reached | Unique anonymous IDs per month |
| Referral completion | Users who confirm they reached a service, and facility records |
| Knowledge gain | Short before-and-after quizzes |
| Answer quality | Clinical spot-checks of a sample of conversations |
| Speech accuracy | Word error rate on a Hausa test set |
| Safety | Safety flags raised and handled; incidents reported |
